# Web 全局页面与资源管理

本说明对应跟进上游 `a189980f` 的未发布工作树。桌面、手机浏览器共用同一套受访问密钥保护的 Web API；文件路径和工具操作都属于运行 Rust 服务的主机。

## 导航与账号

侧栏先列 MCP、Skills、提示词和统一供应商，再列会话、用量和账号。展开侧栏覆盖页面左侧，不改变正文宽度；手机使用导航抽屉。所有供应商及账号引用的供应商名称按显示名 A–Z 排列，忽略大小写；添加供应商时的预设按登录、厂商、第三方、云、本地、插件分节，节内按显示名 A–Z。均不展示赞助、合作、星标或推广排名。故障转移执行队列保持原优先级。

账号中心按 Copilot、ChatGPT、xAI 分组，显示额度、默认账号、重新认证状态及供应商引用。删除账号前会列出受影响的供应商；删除不会自动替这些供应商选择其他账号。供应商表单只负责选择账号。Copilot Enterprise 域名登录仍不支持；禁用入口不会发起认证。各档额度默认写剩余，可在「设置 → 通用 → 外观 → 额度显示」改为已用，颜色仍按剩余算（不到 20% 标橙、用完标红）；余额、ChatGPT 订阅的 Codex Credits 和存下的重置次数始终写剩余，余额用完或欠费时照写金额并标红。

托管 ChatGPT 模型拉取使用指定账号或默认账号的有效凭据；切换账号后迟到结果不覆盖新账号列表。模型发现和生成请求共享客户端身份 `0.159.0`。原生 Codex 官方目录镜像仍使用服务主机检测到的实际 CLI 版本，两者独立。

## MCP 与 Skills

MCP/Skills 单项开关立即显示目标状态，写入失败回滚。列标题批量开关只影响搜索或筛选后可见的结果，成功条目可撤销；失败条目单独报告。Skills 的「已安装」与「发现」在同一页用页签切换：已安装为应用矩阵，表头全选框只选当前筛选出的行，勾选后可批量启用、停用、更新或卸载；发现结果与已安装同为列表行，从发现跳回已安装时对应行会闪烁标出。发现列表按可视区域渲染。

“立即重新同步”（Skills 在页面「⋯」菜单的存储弹窗里）将已保存的启用配置重新投影到应用，报告每个应用及失败技能的原因。MCP 支持 Claude、Codex、Gemini、Grok Build、OpenCode、MiniMax Code；Hermes 的旧 Web MCP 写入仍未支持，不作为成功同步目标。Skills 同步支持上述应用及 Hermes，Desktop、OpenClaw、Pi 的原生目录不由此重新同步接管。

Skills 发现和更新检查同时返回成功条目与失败仓库；存在失败仓库时不能据此判断全部技能已经最新。skills.sh 的重试会重新请求；ZIP 安装跳过重名目录时显示原目录与已安装技能名称。

存储弹窗展示服务主机的实际目录；Skills 从页面「⋯」菜单打开，已安装行的「复制目录路径」复制的也是服务主机上的路径。`auto` 优先符号链接、失败后回退复制；`symlink` 强制符号链接；`copy` 强制复制。迁移主副本沿用存储设置中的确认流程。默认 Web 技能目录是 `~/.cc-switch-web/skills`，不会写入桌面版 `.cc-switch`。

## 提示词、记忆和用量

提示词可复制到其他应用，每个目标创建独立、未启用的新记录，不覆盖同名项。部分失败会保留错误与失败目标，再次复制只重试这些目标。Hermes 的 `SOUL.md` 是人设文件，应按内容选择是否复制。Pi 原生文件导入没有不可执行的撤销入口；删除仍沿用 Web 确认流程。

Hermes 记忆页切换两个文件时保留各自草稿，保存只针对当前文件。用量页显示服务进程最近一次后台或手动扫描的完成时间，每 30 秒刷新；进程尚未扫描时不显示。该时间表示扫描完成，不能代替同步结果中的错误明细。Web 模型测试会实际发起模型请求，因此保留模型、超时和重试设置。

## 新增或调整的 API

所有路径均沿用 Web 访问密钥保护，配置访问密钥时须发送 `Authorization: Bearer <key>`。

| 方法与路径 | 请求与结果 |
| --- | --- |
| `GET /api/auth/codex_oauth/models?accountId=...` | 可省略账号以使用默认账号；返回可选模型列表 |
| `POST /api/mcp/resync` | `{apps?: string[]}`；省略时同步受支持应用，去重目标并返回逐应用结果；不支持的目标返回 400 |
| `POST /api/skills/resync` | 返回逐应用结果及 `failedSkills`；不接管排除应用的原生目录 |
| `GET /api/skills/storage-paths` | 返回 `ccSwitch`、`unified` 两种存储位置的实际路径 |
| `GET /api/skills/discover` | 返回 `{skills, failures}`，失败包含仓库坐标与原因 |
| `GET /api/skills/updates` | 返回 `{updates, failures}`；前端旧数组 API 继续由兼容包装提供 |
| `POST /api/skills/install-archives` | 安装结果增加 `skipped` 诊断，已安装条目照常返回 |
| `GET /api/usage/session-sync` | 返回最近扫描完成的 Unix 毫秒时间或 `null`；既有 POST 仍触发手动同步 |

测试使用临时目录、内存数据库、本地 HTTP 夹具和浏览器全 API mock。真实账号登录、工具安装、跨平台编译、全量测试、发布构建和 Docker 验证不包含在本轮验收内。
