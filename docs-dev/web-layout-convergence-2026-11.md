# 界面布局向上游收敛计划（2026-11）

## 1. 背景与决定

10 月那一轮（[2026-10 台账](web-parity-post-f8788719-2026-10.md)）迁 v7 / v8 改版时保留了 Web 自己的若干布局。本轮基线后的上游提交在这些布局上继续演进，约 15 个只能部分迁移或判不适用。

2026-11-05 用户决定以下四处向上游最终布局（upstream/main）收敛：

1. Skills 发现 / 已安装列表；
2. 供应商卡片布局；
3. 模式界面与表单布局；
4. 设置页与页面文案。

不变的约束：

- 主题保留 Web 自己的 CSS 变量，上游类名映射到 Web 变量（见[预设分组选择器跟进计划](web-preset-selector-catchup-2026-11.md)）。
- 不展示赞助 / 合作标识、不因身份置顶；已保存的供应商列表按显示名称 A–Z，不做拖动排名；故障转移队列保持路由优先级。
- 后端模式控制器（`mode/controller.rs`）与 Web 的 HTTP API 不为布局而重写；界面需要的数据缺口按需补接口。
- 桌面专属（托盘、窗口标题栏、更新器）不适用；「打开目录」类改为显示 / 复制路径。
